### Задание 1 (лёгкое): Первая и последняя буква

Напишите программу, которая запрашивает у пользователя любое слово через команду `input()`.

Программа должна:
1. Посчитать общую длину слова с помощью функции `len()`.
2. Получить первую букву слова по индексу `0`.
3. Получить последнюю букву слова по отрицательному индексу `-1`.
4. Вывести результат на экран, используя f-строку.

**Пример работы:**
```text
Ввод:
  Введите слово: Программирование

Вывод:
  Слово: Программирование
  Длина слова: 16 символов
  Первая буква: П
  Последняя буква: е
```

### Задание 2: Первые шаги со срезами

Создайте в коде переменную со словом:
```python
language = "JavaScript"
```

С помощью срезов извлеките из этой строки:
1. Первые 4 символа (должно получиться слово `"Java"`).
2. Символы, начиная с индекса 4 и до самого конца строки (должно получиться слово `"Script"`).

Выведите оба полученных слова на экран через f-строку.

**Пример вывода на экран:**
```text
Первая часть: Java
Вторая часть: Script
```

### Задание 3: Разбор даты со срезами

Представьте, что программа получает строку с датой в стандартном формате:
```python
date = "2026-10-20"
```

С помощью срезов извлеките из строки `date`:
1. Год (первые 4 символа).
2. Номер месяца (символы между дефисами).
3. День (последние 2 символа).

Соберите и выведите строку в привычном формате с помощью f-строки:

**Пример вывода на экран:**
```text
День: 20
Месяц: 10
Год: 2026
```

### Задание 4* (со звёздочкой — необязательное, для желающих): Проверка спама и превью

Напишите программу для анализа короткого комментария.

Пользователь вводит текст через команду `input()` (например: `"Смотрите фильм бесплатно онлайн"`).

Программа должна:
1. С помощью оператора `in` проверить, содержится ли в тексте опасное слово `"бесплатно"`, и сохранить результат (`True` или `False`) в переменную `is_spam`.
2. С помощью среза взять первые 5 символов сообщения и доклеить к ним строку `"..."`, чтобы получилось короткое превью.
3. Вывести результаты на экран с помощью f-строк.

**Пример работы:**
```text
Ввод:
  Введите текст комментария: Смотрите фильм бесплатно онлайн

Вывод:
  Превью: Смотр...
  Содержит спам: True
```
