## 1. Зачем нужны коллекции

До сих пор одна переменная хранила ровно одно значение:
```python
user1 = "Анна"
user2 = "Алексей"
user3 = "Мария"
```
Если пользователей станет 100 или 1000, заводить под каждого отдельную переменную невозможно. Для хранения групп связанных данных в Python используются **коллекции**.

Самая популярная коллекция — **список (`list`)**. 

Список записывается в квадратных скобках `[]`, а элементы внутри разделяются запятыми:

```python
# Список строк
fruits = ["яблоко", "банан", "апельсин"]

# Список чисел
scores = [10, 25, 42, 99]

# Список с разными типами данных (да, так тоже можно!)
user = ["Алексей", 25, 1.78, True]

# Пустой список
empty_list = []
```

## 2. Индексация и срезы списков

В Уроке 3 мы изучали индексацию и срезы строк. В списках всё работает **абсолютно точно так же**:

```python
fruits = ["яблоко", "банан", "апельсин", "киви"]

# Положительные индексы (с 0)
print(fruits[0])   # яблоко
print(fruits[1])   # банан

# Отрицательные индексы (с конца)
print(fruits[-1])  # киви

# Длина списка
print(len(fruits))  # 4

# Проверка наличия (in)
print("банан" in fruits)  # True
print("груша" in fruits)  # False

# Срезы: [start:end] (end не включается)
print(fruits[1:3])  # ['банан', 'апельсин']
print(fruits[:2])   # ['яблоко', 'банан']
```

## 3. Изменение списков

Главная особенность списка — он **изменяемый** (*mutable*). В отличие от строк, элементы списка можно свободно менять, добавлять и удалять.

### 1. Замена элемента по индексу
Чтобы заменить значение, просто обращаемся по индексу со знаком `=`:

```python
fruits = ["яблоко", "банан", "апельсин"]
fruits[1] = "груша"

print(fruits)  # ['яблоко', 'груша', 'апельсин']
```

### 2. Добавление в конец: метод `.append()`
Метод `.append()` добавляет новый элемент в самый конец списка:

```python
tasks = ["купить молоко", "помыть посуду"]
tasks.append("позвонить маме")

print(tasks)  # ['купить молоко', 'помыть посуду', 'позвонить маме']
```

### 3. Удаление по значению: метод `.remove()`
Метод `.remove(значение)` находит первое совпадение и удаляет его:

```python
fruits = ["яблоко", "банан", "апельсин"]
fruits.remove("банан")

print(fruits)  # ['яблоко', 'апельсин']
```
> [!WARNING]
> Если попытаться удалить элемент, которого нет в списке (`fruits.remove("манго")`), Python выдаст ошибку `ValueError: list.remove(x): x not in list`.

### 4. Удаление по индексу: метод `.pop()`
Метод `.pop()` вырезает элемент из списка. Если вызвать его без аргументов `pop()`, он удалит **самый последний** элемент:

```python
numbers = [10, 20, 30]
last_item = numbers.pop()

print(last_item)  # 30
print(numbers)    # [10, 20]
```
Если передать индекс `numbers.pop(0)`, удалится элемент с этим номером.

## 4. Функция range()

Часто программистам нужны списки с числами (например, от 1 до 100 или от 0 до 50 с шагом 5). Набивать их руками не нужно — для этого есть встроенная функция **`range()`** (диапазон).

Функция `range(start, stop, step)` принимает до трёх параметров:

### 1. Только правая граница: `range(stop)`
Генерирует числа от `0` до `stop - 1` (правая граница не включается):
```python
# Чтобы увидеть числа, преобразуем range в список через list():
numbers = list(range(5))
print(numbers)  # [0, 1, 2, 3, 4]
```

### 2. Начало и конец: `range(start, stop)`
Генерирует числа от `start` до `stop - 1`:
```python
numbers = list(range(1, 6))
print(numbers)  # [1, 2, 3, 4, 5]
```

### 3. С шагом: `range(start, stop, step)`
Шаг показывает, через сколько чисел двигаться:
```python
# Чётные числа от 0 до 8:
evens = list(range(0, 10, 2))
print(evens)  # [0, 2, 4, 6, 8]

# Обратный отсчёт (отрицательный шаг):
countdown = list(range(5, 0, -1))
print(countdown)  # [5, 4, 3, 2, 1]
```

> [!NOTE]
> Заметили? Параметры `range(start, stop, step)` работают точно так же, как срезы строк `[start:stop:step]`!

## 5. Кортежи (tuple)

**Кортеж (`tuple`)** — это «родной брат» списка, но с одним главным отличием: **кортеж нельзя изменить**.

Синтаксис: круглые скобки `()` вместо квадратных:

```python
# Кортеж координат
point = (55.75, 37.61)

# Кортеж цветов светофора
traffic_lights = ("красный", "желтый", "зеленый")
```

В кортежах работают все операции чтения:
```python
print(traffic_lights[0])   # красный
print(traffic_lights[-1])  # зеленый
print(len(traffic_lights)) # 3
print("зеленый" in traffic_lights) # True
```

### Почему нельзя изменить кортеж?
Если попытаться добавить элемент или перезаписать существующий:
```python
traffic_lights[0] = "синий"
```
Python сразу остановит программу:
```text
TypeError: 'tuple' object does not support item assignment
```
*(«Объект кортежа не поддерживает перезапись элементов»)*.

У кортежа нет методов `.append()`, `.remove()` или `.pop()`.

### Зачем нужны кортежи, если есть списки?
1. **Защита от случайных изменений**: если данные не должны меняться ни при каких обстоятельствах (дни недели, месяцы года, координаты, настройки системы) — используйте кортеж.
2. **Скорость и память**: кортежи работают быстрее списков и занимают меньше памяти.
