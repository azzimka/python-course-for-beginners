## Зачем нужны типы данных

В реальной жизни мы постоянно работаем с разной информацией. Представьте простую анкету человека:
- **Имя**: «Алексей» — это текст (буквы).
- **Возраст**: `25` — это целое число. С ним можно производить вычисления: например, узнать, сколько лет будет через год.
- **Рост**: `1.78` — это число с дробной частью.
- **Есть ли водительские права?**: `Да` (правда) или `Нет` (ложь) — логический ответ.

Компьютер не может относиться ко всей этой информации одинаково. Текст нельзя умножить на другой текст, а дробное число пишется иначе, чем целое. Поэтому в Python у каждого объекта есть свой **тип данных**.

## Четыре простых типа данных

### 1. Строки — `str` (string)
Любой текст, заключённый в кавычки (одинарные или двойные):
```python
first_name = "Анна"
city = 'Ташкент'
empty_text = ""
```
Даже цифра в кавычках `"100"` для Python становится текстом, а не числом.

### 2. Целые числа — `int` (integer)
Положительные, отрицательные числа и ноль без дробной части:
```python
age = 20
temperature = -5
coins = 0
```

### 3. Числа с плавающей точкой — `float` (floating-point number)
Дробные числа. В Python дробная часть отделяется **точкой**, а не запятой:
```python
price = 19.99
pi = 3.1415
weight = 65.0
```
Обратите внимание: `65.0` — это тип `float`, хотя дробная часть равна нулю.

### 4. Логический тип — `bool` (boolean)
Принимает всего два значения:
- `True` — истина (да / правда)
- `False` — ложь (нет / неправда)

Оба слова пишутся строго с **заглавной буквы** и без кавычек:
```python
is_student = True
has_driver_license = False
```

## Функция type() — проверка типа

Чтобы узнать, какой тип данных у объекта или переменной, в Python есть встроенная функция `type()`:

```python
user_name = "Alex"
user_age = 25
user_rating = 4.9
is_active = True

print(type(user_name))    # <class 'str'>
print(type(user_age))     # <class 'int'>
print(type(user_rating))  # <class 'float'>
print(type(is_active))    # <class 'bool'>
```
Слово `class` в выводе означает «тип/класс данных».

## Динамическая и строгая типизация

Python устроен очень умно, но при этом требует аккуратности. О его типизации важно знать две вещи:

### 1. Типизация динамическая
Вам не нужно заранее объявлять тип переменной, как в некоторых других языках (C++, Java). Python сам определяет тип на лету в момент присваивания значения:
```python
data = 10        # Python понял, что это int
data = "Текст"   # Теперь переменная указывает на строку str
```

### 2. Типизация строгая
Python **никогда не смешивает несовместимые типы автоматически**. 

Если вы попытаетесь сложить строку и число:
```python
print("Мне " + 20)
```
Python не станет угадывать, что вы имели в виду, а сразу остановит программу с ошибкой:
```text
TypeError: can only concatenate str (not "int") to str
```
*(«Ошибка типа: к строке можно присоединять только строку, а не int»)*.

Точно так же нельзя сложить строку `"5"` и число `10`:
```python
print("5" + 10)  # Снова TypeError!
```
Чтобы такие операции сработали, программист должен **явно** преобразовать один тип данных в другой.

## Преобразование типов

Преобразование типа (приведение типов) — это перевод данных из одного типа в другой с помощью специальных функций.

### 1. Преобразование в строку — `str()`
Функция `str()` превращает любое значение в текст. Это нужно, например, чтобы соединить текст с числом через знак `+`:
```python
age = 25
message = "Мне " + str(age) + " лет"
print(message)  # Выведет: Мне 25 лет
```

### 2. Преобразование в целое число — `int()`
Функция `int()` превращает текст из цифр или дробное число в целое число:
```python
text_number = "100"
real_number = int(text_number)
print(real_number + 50)  # Выведет: 150

price = 19.99
print(int(price))        # Выведет: 19 (дробная часть просто отбрасывается)
```

### 3. Преобразование в дробное число — `float()`
Функция `float()` переводит текст или целое число в формат с плавающей точкой:
```python
text_height = "1.75"
height = float(text_height)
print(height + 0.05)     # Выведет: 1.8

score = 5
print(float(score))      # Выведет: 5.0
```

### Ошибка ValueError — когда преобразование невозможно

Python может превратить в число только то, что действительно является числом. Если попытаться передать неподходящий текст, программа аварийно завершится с ошибкой **`ValueError`** (недопустимое значение):

```python
number = int("Привет")
```
В консоли появится:
```text
ValueError: invalid literal for int() with base 10: 'Привет'
```
*(«Недопустимый текст для превращения в целое число: 'Привет'»)*.

> [!WARNING]
> Ошибка `ValueError` возникнет и в таком случае:
> ```python
> number = int("3.14")  # Ошибка!
> ```
> Внутри строки `"3.14"` есть точка, поэтому функция `int()` не понимает такой формат. Сначала эту строку нужно преобразовать через `float("3.14")`.

## Ввод чисел с клавиатуры: int(input()) и float(input())

На первом уроке мы узнали, что команда `input()` **всегда возвращает текст (строку)**, даже если пользователь напечатал цифры.

Теперь мы знаем, как решить эту проблему! Чтобы работать с числами, ввод сразу оборачивают в `int()` или `float()`:

### Ввод целых чисел
```python
num1 = int(input("Введите первое число: "))
num2 = int(input("Введите второе число: "))

total = num1 + num2
print("Сумма чисел:", total)
```
Теперь, если ввести `5` и `3`, программа сложит их математически и выведет `8`, а не склеит в `53`!

### Ввод дробных чисел
Если ожидается число с точкой (цена, вес, расстояние), используйте `float()`:
```python
price = float(input("Введите стоимость товара: "))
discount = float(input("Введите скидку (в рублях): "))

final_price = price - discount
print("Итого к оплате:", final_price)
```
