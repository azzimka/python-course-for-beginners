# Методы и операции со словарями (dict)


Представьте наш рабочий словарь пользователя:

```python
user = {
    "name": "Алексей",
    "city": "Ташкент",
    "age": 25
}
```

---

## 1. Получение значения по ключу: `d[key]` vs `.get()`

Первый и самый простой способ достать значение — обратиться к нему в квадратных скобках по имени ключа:

```python
print(user["name"])  # Алексей
```

> [!WARNING]
> Если вы запросите ключ, которого в словаре нет:
> ```python
> print(user["email"])  # 💥 KeyError: 'email'
> ```
> Программа сразу аварийно завершится с ошибкой `KeyError`.

### Безопасное получение: метод `.get()`
Чтобы программа не ломалась, у словарей есть метод **`.get()`**. Это наша подушка безопасности: если ключ существует — он вернёт значение, а если нет — программа спокойно продолжит работу и вернёт `None` (или запасной ответ, который вы сами укажете):

```python
# Ключа "email" нет, но ошибки не будет:
print(user.get("email"))  # None

# Можно передать свой ответ по умолчанию:
print(user.get("email", "Почта не указана"))  # Почта не указана
```

---

## 2. Добавление и изменение данных

Словари в Python — **изменяемые** (*mutable*). Менять их очень просто:

```python
# Если ключ уже ЕСТЬ — значение перезапишется:
user["age"] = 26

# Если ключа НЕТ — создастся новая пара «ключ-значение»:
user["job"] = "Python-разработчик"

print(user)
# {'name': 'Алексей', 'city': 'Ташкент', 'age': 26, 'job': 'Python-разработчик'}
```

---

## 3. Удаление данных: метод `.pop()`

Если данные больше не нужны, удалить их можно с помощью уже знакомого нам метода **`.pop(key)`**:

```python
# Удаляем пару по ключу и сохраняем удалённое значение в переменную:
deleted_age = user.pop("age")

print(deleted_age)  # 26
print(user)         # останутся только 'name', 'city' и 'job'
```

---

## 4. Методы `.keys()`, `.values()`, `.items()`

Часто нам нужно посмотреть на словарь со стороны: отдельно взглянуть на список всех ключей, отдельно на значения или на пары целиком:

```python
student = {
    "name": "Анна",
    "course": "Python",
    "grade": 5
}

# 1. .keys() — получаем только ключи:
print(student.keys())
# dict_keys(['name', 'course', 'grade'])

# 2. .values() — получаем только значения:
print(student.values())
# dict_values(['Анна', 'Python', 5])

# 3. .items() — получаем пары «ключ-значение» в виде кортежей:
print(student.items())
# dict_items([('name', 'Анна'), ('course', 'Python'), ('grade', 5)])
```
