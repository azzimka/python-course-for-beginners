### Задание 1. Платёжный терминал: пополнение кошелька и открытие счёта

**Сценарий:**  
Вы разрабатываете логику для мультивалютного платёжного терминала. Пользователь подходит к терминалу и вносит наличные на свой электронный кошелёк. У пользователя уже могут быть открыты счета в некоторых валютах, а некоторые валюты он пополняет впервые.

**Исходные данные:**
```python
# Валюты, которые поддерживает терминал:
supported_currencies = ["USD", "EUR", "RUB", "UZS"]

# Текущий кошелёк пользователя:
wallet = {
    "USD": 50,
    "EUR": 20
}
```

**Что нужно сделать:**
1. Запросите у пользователя название валюты отдельным вводом:
   ```python
   currency = input("Введите валюту (USD, EUR, RUB, UZS): ").upper().strip()
   ```
2. Запросите сумму пополнения вторым отдельным вводом и преобразуйте её в число:
   ```python
   amount = int(input("Введите сумму пополнения: "))
   ```
3. С помощью оператора **`not in`** проверьте, принимает ли терминал такую валюту:
   - Если валюта **не** поддерживается терминалом — выведите сообщение:  
     `"Ошибка: терминал не принимает валюту [currency]!"`
4. Если валюта поддерживается:
   - С помощью оператора **`in`** проверьте, есть ли уже такая валюта в словаре `wallet`:
     - **Если валюта уже есть:** прибавьте сумму к текущему балансу (`wallet[currency] += amount`) и выведите:  
       `"Счёт [currency] успешно пополнен на [amount]."`
     - **Если валюты ещё нет:** создайте в словаре новый ключ с начальным значением `amount` (`wallet[currency] = amount`) и выведите:  
       `"Открыт новый счёт [currency] с балансом [amount]."`
5. В конце программы выведите итоговое состояние кошелька `wallet`.

**Пример работы 1 (пополнение существующего счёта):**
```text
Введите валюту (USD, EUR, RUB, UZS): USD
Введите сумму пополнения: 30
Счёт USD успешно пополнен на 30.
Итоговый кошелёк: {'USD': 80, 'EUR': 20}
```

**Пример работы 2 (открытие нового счёта):**
```text
Введите валюту (USD, EUR, RUB, UZS): UZS
Введите сумму пополнения: 150000
Открыт новый счёт UZS с балансом 150000.
Итоговый кошелёк: {'USD': 50, 'EUR': 20, 'UZS': 150000}
```

**Пример работы 3 (неподдерживаемая валюта):**
```text
Введите валюту (USD, EUR, RUB, UZS): JPY
Введите сумму пополнения: 5000
Ошибка: терминал не принимает валюту JPY!
Итоговый кошелёк: {'USD': 50, 'EUR': 20}
```

### Задание 2: Безопасный переводчик (.get)

Создайте словарь-переводчик с английского на русский (5–6 слов на ваш выбор):
```python
dictionary = {
    "cat": "кот",
    "dog": "собака",
    "book": "книга",
    "sun": "солнце",
    "python": "питон"
}
```

Напишите программу, которая:
1. Запрашивает у пользователя английское слово через команду `input()`.
2. С помощью безопасного метода **`.get()`** ищет перевод:
   - Если слово найдено — выводит перевод.
   - Если слова нет в словаре — выводит фразу: `"К сожалению, этого слова нет в словаре"`.

**Пример работы 1:**
```text
Ввод:
  Введите слово на английском: book

Вывод:
  Перевод: книга
```

**Пример работы 2:**
```text
Ввод:
  Введите слово на английском: car

Вывод:
  К сожалению, этого слова нет в словаре
```

### Задание 3: Меню кофейни (keys, in, pop)

Дан словарь с меню кофейни и ценами на напитки:
```python
menu = {
    "эспрессо": 120,
    "капучино": 180,
    "латте": 200,
    "раф": 220
}
```

Напишите программу, которая:
1. С помощью метода `.keys()` выводит список всех напитков из меню.
2. Запрашивает у пользователя название напитка через `input()`.
3. С помощью оператора **`in`** проверяет, есть ли такой напиток:
   - Если есть: выводит его стоимость в рублях.
   - Если нет: сообщает `"Такого напитка в меню нет"`.
4. Сезон напитка `"раф"` подошёл к концу. Удалите его из словаря с помощью метода `.pop()` и выведите обновлённое меню на экран.

**Пример работы:**
```text
Меню сегодня: dict_keys(['эспрессо', 'капучино', 'латте', 'раф'])
Какой напиток вы хотите: латте
Цена: 200 руб.

Обновлённое меню: {'эспрессо': 120, 'капучино': 180, 'латте': 200}
```

### Задание 4* (со звёздочкой — необязательное, для желающих): Расчёт корзины и скидка

В интернет-магазине сформирована корзина покупок:
```python
cart = {
    "ноутбук": 45000,
    "мышка": 1500,
    "клавиатура": 3500,
    "наушники": 5000
}
```

Напишите программу, которая:
1. Выводит список купленных товаров (через `.keys()`).
2. С помощью функции `sum()` и метода **`.values()`** вычисляет общую стоимость всех товаров в корзине:
   ```python
   total = sum(cart.values())
   ```
3. Проверяет условие с помощью `if / else`:
   - Если общая сумма заказа **больше 50 000 рублей**, магазин дарит скидку **10%** (`total * 0.9`). Программа выводит поздравление со скидкой и итоговую сумму к оплате.
   - Иначе: выводит сумму без скидки.

**Пример вывода на экран:**
```text
Товары в чеке: dict_keys(['ноутбук', 'мышка', 'клавиатура', 'наушники'])
Сумма заказа: 55000 руб.
Поздравляем! Вам начислена скидка 10%.
Итого к оплате: 49500.0 руб.
```
