# Python · Блок «Разработка на Python»

Учебные материалы курса: теория и домашние задания по каждому уроку.

Курс рассчитан для новичков


## Как пользоваться

1. Открой папку нужного месяца, затем папку урока.
2. Прочитай `lesson.md` — там теория урока.
3. Открой `homework.py` — там задания. Код пиши у себя на компьютере
   в отдельном файле, этот файл — только список заданий.
